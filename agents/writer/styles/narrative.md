# 文风：narrative · 娓娓道来

> 源自 `liurun-bookwriter-skills`（罗振宇 style-dna）蒸馏改写，MIT。量化指标以
> `shared/config/quality-gates.json` → `styles.narrative` 为唯一事实源。

## 定位
娓娓道来式文风：用时间纵深把概念讲成一个「有来路、有转折、有落点」的故事。擅长跨域联想
（把一个领域的事件接驳到另一个领域），每个大段落用金句收束，让读者读完有「被击中」的感觉。
它不是编故事，而是把真实史料按叙事逻辑重新排列。

## 句式指纹
- 单句 ≤ 40 字；动词占比 ≥ 1/3（叙事靠动词推进，不靠形容词堆叠）。
- 每千字 ≥ 2 个有细节的故事/案例（必须含具体时间、人物、动作，不许「据说」）。
- 金句必须现场原创，至少覆盖以下句式中的一种：对仗式 / 重定义式 / 反常识式 / 「一X就Y」式 / 工具式 / 二元解构式 / 数字式。
- 每篇 ≥ 1 个「躬身入局」框：作者亲自下场代入一个角色或场景，以「我」展开。

## 词汇特征
- 人称配额（每千字）：「我」≥ 4 次、「你」≥ 3 次、「我们」≤ 5 次、「大家」= 0。
- 偏爱时间标记词（「此后」「直到」「转折发生在」），但禁止机械连接词（首先/其次/最后）。
- 禁用抽象升华与万能结尾（「希望通过本文……」）。

## 量化指标
见 `shared/config/quality-gates.json` → `styles.narrative`：
- `max_sentence_max: 40`、`golden_sentence_per_1000_min: 3`、`stories_per_1000_min: 2`
- `verb_ratio_min: 0.33`、`immersion_box_min: 1`
- `i_per_1000_min: 4`、`you_per_1000_min: 3`、`we_per_1000_max: 5`、`dajia_per_1000_max: 0`

## 与 tone 叠加规则
- `tone=editorial` 与本风格天然亲和（短句、画面感），可放宽金句密度但不得低于 3 句/千字。
- `tone=academic` 时故事替换为「研究现场还原」（论文写作时的动机、实验转折），引用密度规则不变且优先。
- `tone=popular` 时跨域联想更自由，但每个联想必须可被材料支撑，禁止空转。

## 样例
> 1947 年的贝尔实验室，一个年轻人盯着示波器上的噪声曲线发呆。那团乱麻一样的信号，
> 后来被证明是宇宙诞生时留下的余温——这个发现晚了 17 年才被确认，因为它太像「设备故障」了。
> 你看，科学史上最贵的答案，往往伪装成最廉价的错误。
> 今天要讲的这个词，走的也是这条路：先被当成杂音，再被当成噪声，最后才被认作信号。
