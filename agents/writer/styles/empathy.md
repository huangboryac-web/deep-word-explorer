# 文风：empathy · 设身处地

> 源自 `liurun-bookwriter-skills`（刘润 style-dna）蒸馏改写，MIT。量化指标以
> `shared/config/quality-gates.json` → `styles.empathy` 为唯一事实源。

## 定位
设身处地式文风：全文保持「对象感」，把读者当成一个具体的、正在为某个问题焦虑的人。
不是讲道理，而是陪读者把问题拆开看。逻辑势能采用 SCQA（情境-冲突-疑问-回答）推进，
关键处用金句钉住记忆点，用商业世界或日常经营的类比让抽象概念落地。

## 句式指纹
- 单句 ≤ 45 字；多用「你」直接对话，少用「我们」「大家」这类模糊群体指称。
- 开头 3 段内必须建立同理心锚点：说出读者此刻可能的困惑、成本或代价。
- 每篇至少 1 个完整的 SCQA 节点（情境 → 冲突 → 疑问 → 回答），冲突要具体、有代价。
- 金句放在段末或节点转折处，用来「收」住一段论述。

## 词汇特征
- 高使用：「你」「你的处境」「对你来说」「不妨算一笔账」。
- 零容忍：「大家」（统计口径见量化指标）；商业黑话（赋能 / 抓手 / 底层逻辑 / 打通 / 闭环）。
- 类比偏好商业、经营、日常决策场景，避免纯学术比喻。

## 量化指标
见 `shared/config/quality-gates.json` → `styles.empathy`：
- `max_sentence_max: 45`
- `you_per_1000_min: 8`（每千字「你」≥ 8 次）、`i_per_1000_min: 3`（「我」≥ 3 次）
- `dajia_per_1000_max: 0`（「大家」零容忍）
- `golden_sentence_per_1000_min: 2`（金句 ≥ 2 句/千字）、`scqa_nodes_min: 1`（SCQA 节点 ≥ 1）
- 禁用：`forbidden_business_jargon`（赋能 / 抓手 / 底层逻辑 / 打通 / 闭环）

## 与 tone 叠加规则
- `tone=popular`：类比更多、对象感更浓；`tone=academic`：SCQA 的冲突改为「文献中的分歧」；
  `tone=editorial`：金句密度可上调至 3 句/千字，段落更短。
- tone 的引用密度与术语规则始终优先；本风格不得为「对象感」牺牲引用与术语准确。

## 样例
> 你可能已经注意到了：同样是「学习一个新概念」，有人一小时就上手，有人卡了一周。
> 差的不是智商，而是入口。今天这个词，就是那个被人绕开的入口。
> 为了理解它，你只需要先回答一个问题：为什么看起来越简单的定义，越容易让人误解？
> 把这个问题想清楚，剩下的部分，几乎是一路下坡。
