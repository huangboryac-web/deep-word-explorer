# 引用格式规范 (Citation Format)

本文档定义深度词汇解析文章的引用标注和参考文献格式。

---

## 一、文内引用格式

### 基本格式
在需要引用的句子/段落末尾，使用上标数字标记：`[N]`

### 引用位置
- 放在句号/逗号之前
- 如果引用整段，放在段末句号之前
- 如果引用特定数据/论断，紧跟该数据/论断之后

### 示例
```
萨特在1943年发表的《存在与虚无》中系统阐述了存在主义的核心命题[3]，
这一著作被公认为存在主义的奠基之作。

存在主义强调"存在先于本质"[2]，这一论断颠覆了传统哲学对人的理解。
```

### 引用密度
- 每阶最少 2 条引用
- 全文最少 12 条引用
- 每个核心论断至少 1 条引用
- 有争议的内容必须有引用支撑

## 二、参考文献列表格式

### 总体布局
参考文献在文章末尾，分三组排列：

1. **学术来源**（Academic Sources）：论文、学术著作、领域百科
2. **官方来源**（Official Sources）：政府/机构报告、官方数据、行业标准
3. **深度内容**（Deep Content）：专业博客、深度报道、书籍（非学术类）、专家文章

### 每组格式

#### 学术来源
```
[编号] 作者. (年份). 标题. 出版物/期刊名, 卷(期), 页码. URL

示例：
[1] Sartre, J.-P. (1943). L'Être et le Néant. Gallimard.
[2] Heidegger, M. (1927). Sein und Zeit. Max Niemeyer Verlag.
[3] 陈嘉映. (2015). 存在与时间读本. 生活·读书·新知三联书店.
```

#### 官方来源
```
[编号] 机构名. (年份). 报告/文件标题. URL

示例：
[4] UNESCO. (2023). World Heritage List: The Great Wall. https://whc.unesco.org/...
[5] 国家统计局. (2024). 中国统计年鉴2024.
```

#### 深度内容
```
[编号] 作者. (年份). 标题. 平台/出版物. URL. 访问日期.

示例：
[6] 张某. (2022). 存在主义入门：从克尔凯郭尔到萨特. 知乎. https://zhihu.com/.... 访问于 2026-08-07.
```

## 三、特殊引用情况

### 网页/在线资源
```
作者/机构. (发布日期或"n.d."). 页面标题. 网站名. URL. 访问日期.
```

### 无明确作者
```
"页面标题". (年份). 网站名. URL. 访问日期.
```

### 视频/播客
```
创作者. (发布日期). 视频/播客标题 [类型]. 平台名. URL.
```

### 社交媒体
```
作者 [@用户名]. (发布日期). 帖子内容摘要 [帖子类型]. 平台名. URL.
注：社交媒体引用仅作为补充，不作为核心论证的主要支撑
```

## 四、HTML 中的引用渲染

### 文内标注
使用 `<sup class="citation-ref" data-cite-id="N">[N]</sup>` 渲染
Hover 效果：显示完整的引用条目（author, title, year）

### 底部参考文献
使用有序列表 + 三组标题：
```html
<section class="references">
  <h2>参考文献</h2>

  <div class="ref-group" data-ref-type="academic">
    <h3>📚 学术来源</h3>
    <ol>...</ol>
  </div>

  <div class="ref-group" data-ref-type="official">
    <h3>🏛 官方来源</h3>
    <ol>...</ol>
  </div>

  <div class="ref-group" data-ref-type="deep-content">
    <h3>📖 深度内容</h3>
    <ol>...</ol>
  </div>
</section>
```
