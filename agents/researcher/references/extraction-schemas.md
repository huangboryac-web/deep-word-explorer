# 数据提取 Schema (Extraction Schemas)

本文档定义深度词汇解析引擎每层搜索的数据提取规则。每层有独立的提取 schema、字段要求、质量门禁和字数指导。

---

## Layer 1 · 骨架层提取

### 提取目标
从百科/词典/结构化数据库中提取最基础的、无可争议的事实信息。

### 提取方法
1. 读取 Wikipedia、百度百科、Wikidata 返回的内容
2. 按以下字段逐项提取
3. 如多个来源有冲突，以源语言的权威来源为准
4. 每个提取字段标注来源

### 字段规范

| 字段 | 要求 | 来源 | 示例 |
|------|------|------|------|
| `definition` | 1-2 句精准定义，50-200 字 | 百科首段 | "存在主义是一种哲学思潮，强调个体存在的优先性……" |
| `aliases` | 所有别名/译名/简称 | 百科别名栏 + Wikidata | ["实存主义", "Existentialism"] |
| `category.primary` | 最精确的分类 | Wikidata instance_of | "哲学流派" |
| `category.secondary` | 2-3 个辅助分类 | Wikidata | ["20世纪哲学", "欧陆哲学"] |
| `timeline` | 5-20 个关键时间节点，按时间排序 | 百科历史章节 | [{date: "1943", event: "萨特出版《存在与虚无》", ...}] |
| `key_figures` | 3-10 个关键人物 | 百科关联人物 | [{name: "萨特", role: "创始人", contribution: "……"}] |
| `geographic_scope` | 一句话概括地理范围 | 百科 + 常识 | "主要起源于法国，后传播至全球" |
| `parent_concepts` | 3-5 个上位概念 | Wikidata subclass_of 链 | ["哲学", "欧陆哲学", "现象学"] |
| `etymology` | 词源解析（如有） | 百科词源章节 | "源自拉丁语 existentia，意为'存在'" |
| `quick_stats` | 快速关键数字（如有） | 百科 infobox | {"首次提出": "19世纪", "代表人物数": "10+", ...} |

### 质量门禁
- `definition` 非空且 ≤ 200 字
- `timeline` 节点数 ≥ 2
- `key_figures` 数量 ≥ 1
- 每个字段有明确来源

## Layer 2 · 学术层提取

### 提取目标
从学术论文和权威出版物中提取深度学术信息。

### 提取方法
1. 搜索 Google Scholar + 领域百科
2. 取被引量最高的前 5 篇论文摘要
3. 阅读领域百科（如 SEP）的完整条目
4. 按以下字段提取
5. 注意：不同论文的观点如有冲突，全部记录并标注分歧

### 字段规范

| 字段 | 要求 | 来源 | 字数/条数 |
|------|------|------|----------|
| `consensus_view` | 学术界对该概念的主流共识（综合多篇论文） | 高被引论文 + 领域百科 | 500-1000 字 |
| `key_debates` | 核心争议，每条约 100-200 字 | 论文摘要中的对立观点 | 至少 1 条，最多 5 条 |
| `milestone_papers` | 里程碑式论文/著作 | 被引量排序 + 领域百科引用 | 3-8 篇 |
| `schools_of_thought` | 主要学派/流派 | 领域百科 + 论文分类 | 1-5 个学派 |
| `latest_research_directions` | 最新研究方向（近 5 年） | 论文摘要中提及的"future work" | 3-8 个方向 |

### 每篇论文提取子字段
```
{
  "title": "论文标题",
  "authors": "第一作者 et al.",
  "year": 2020,
  "venue": "期刊/会议名",
  "citation_count": 被引数（从 Google Scholar 获取）,
  "core_contribution": "一句话概括核心贡献（50字以内）",
  "url": "论文链接（如有）"
}
```

### 质量门禁
- `consensus_view` 非空 或 `key_debates` 数量 ≥ 1
- `milestone_papers` 数量 ≥ 2
- 每个条目有来源 URL

## Layer 3 · 专家层提取

### 提取目标
从专家/深度内容平台中提取通俗解读、类比、误解和学习建议。

### 提取方法
1. 搜索知乎（>500赞）、Medium、Substack、豆瓣高分书籍等
2. 优先选择作者有明确领域背景的内容
3. 提取对普通读者最有帮助的理解角度

### 字段规范

| 字段 | 要求 | 来源 | 字数/条数 |
|------|------|------|----------|
| `expert_interpretations` | 专家解读，每个 200-400 字 | 知乎/Mdium/博客 | 2-5 条 |
| `vivid_analogies` | 生动类比，每个含类比 + 解释 + 领域 + 准确性说明 | 知乎/视频/科普 | 3-5 条 |
| `common_misconceptions` | 常见误解及纠正 | 知乎/Quora/科普 | 2-5 条 |
| `learning_path` | 推荐学习路径 | 专家建议 + 综合 | 3-6 步 |

### 专家解读质量评级
- **A 级**：作者为领域内公认专家，内容有引用来源 → trust_score: 0.9+
- **B 级**：作者有相关背景但非知名专家，内容逻辑自洽 → trust_score: 0.7-0.9
- **C 级**：作者背景不明但内容质量高，有外部验证 → trust_score: 0.5-0.7

### 类比质量要求
- 至少包含 3 个不同来源领域（如物理、日常生活、生物各一）
- 每个类比必须标注局限性（"这个类比不完美的地方在于……"）

### 质量门禁
- `expert_interpretations` 数量 ≥ 2
- `vivid_analogies` 数量 ≥ 2
- 每个条目有来源 URL
- 至少 1 个 A 级或 B 级解读

## Layer 4 · 关联层提取

### 提取目标
构建概念关联网络，帮助读者理解"知识图谱"中的位置。

### 提取方法
1. Wikidata SPARQL：查询 subclass_of、instance_of 关系
2. Google Scholar：查询引用关系和"Related articles"
3. 知识推理：从 Layer 1/2/3 的信息中推导关联

### 字段规范

| 字段 | 要求 | 说明 |
|------|------|------|
| `prerequisites` | 3-5 个前置概念 | 每个概念附带「为什么是前置」的解释和一句话简介 |
| `parallel_concepts` | 3-5 个平行概念 | 每个概念附带相似点和差异点 |
| `downstream_concepts` | 3-5 个下游概念 | 每个概念附带与主概念的关系描述 |
| `concept_map_edges` | 5-15 条边 | 每条边包含 from/to/relationship/strength |

### 关系类型定义
- `is_a`：主概念是目标概念的子类
- `part_of`：主概念是目标概念的组成部分
- `influences`：主概念影响目标概念
- `contrasts_with`：两概念形成对比
- `precedes`：主概念在逻辑/历史上先于目标概念
- `evolved_from`：主概念从目标概念演变而来
- `analogous_to`：两概念在不同领域有相似结构

### 质量门禁
- `concept_map_edges` 数量 ≥ 5（或 depth=quick 则跳过整层）
- 覆盖全部 5 种以上关系类型

## Layer 5 · 时效层提取

### 提取目标
捕捉概念的最新发展和公众热议，确保文章时效性。

### 提取方法
1. 搜索近 6 个月的新闻（Google News + 百度资讯）
2. 分析社交媒体趋势（微博 + Twitter/X + Reddit）
3. 查找最新行业报告

### 字段规范

| 字段 | 要求 | 来源 | 字数/条数 |
|------|------|------|----------|
| `recent_developments` | 最新发展，按时间倒序 | 新闻聚合 | 3-8 条 |
| `public_sentiment.overall_tone` | 公众情绪总体基调（正面/负面/中性/两极分化） | 社交媒体分析 | — |
| `public_sentiment.key_narratives` | 主流叙事角度 | 社交媒体分析 | 3-5 条 |
| `trend_analysis` | 趋势分析（热度走向+原因） | 综合分析 | 200-400 字 |
| `future_projections` | 未来预测 | 行业报告+专家评论 | 3-5 条 |

### 质量门禁
- `recent_developments` 数量 ≥ 3
- 趋势分析 ≥ 200 字

---

## 通用提取原则

1. **来源标注**：每个事实信息必须标注来源 URL
2. **不确定性表达**：不确定的信息用「据[来源]称」「[来源]推测」「学界一般认为」等修饰
3. **矛盾记录**：遇到相互矛盾的信息，两条都记录并标注「与[另一来源]的结论不同」
4. **范围约束**：只提取与主概念直接相关的信息，不提取泛化的上下文
5. **时效标注**：每个来源标注 access_date（访问日期）
