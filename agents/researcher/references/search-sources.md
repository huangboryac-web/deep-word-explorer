# 搜索源清单与优先级矩阵

本文档定义深度词汇解析引擎的全部可用搜索源，按五层漏斗分类，每层内按优先级排列。

---

## Layer 1 · 骨架层（百科全书/词典/结构化数据库）

### 始终包含

| 优先级 | 来源 | 类型 | 说明 | 访问方式 |
|--------|------|------|------|---------|
| **P0** | Wikipedia | 百科全书 | 最全面的开放百科，多语言版本 | WebFetch + API |
| **P0** | 百度百科 | 百科全书 | 中文语境最常用的百科 | WebFetch |
| **P0** | Wikidata | 结构化数据库 | 知识图谱，提供分类、属性、关联实体 | SPARQL API |

### 按本体类型补充

| 本体类型 | 补充来源 | 说明 |
|---------|---------|------|
| 学术术语 | Britannica、Stanford Encyclopedia of Philosophy | 权威学术百科 |
| 科技名词 | 维基百科（英文）、MDN Web Docs、DevDocs | 技术文档百科 |
| 地理实体 | OpenStreetMap、GeoNames、UNESCO 世界遗产名录 | 地理信息数据库 |
| 人物 | 维基语录（Wikiquote）、IMDb（影视人物）、DBLP（计算机科学家） | 人物数据库 |
| 组织/机构 | Crunchbase（公司）、联合国会员国名录 | 机构数据库 |
| 文化符号 | IMDb（电影）、豆瓣（书籍/电影）、Goodreads（书籍） | 文化作品数据库 |
| 经济概念 | Investopedia、MBA 智库百科 | 经济/金融百科 |
| 历史概念 | Encyclopædia Britannica（历史条目）、中国大百科全书 | 历史权威百科 |

## Layer 4 · 关联层

Layer 4 的数据主要来源于 Layer 1 的 Wikidata 关联查询和 Layer 2 论文的参考文献/被引分析，而非独立搜索。

| 来源 | 用途 | 说明 |
|------|------|------|
| Wikidata SPARQL | 查询概念的父子关系、相关概念 | 结构化知识图谱 |

## 全局规则

### 优先级使用规则
1. 每层按 P0 → P1 → P2 顺序搜索
2. P0 源得到足够信息后，P1/P2 源仅做补充验证
3. 不可跳过 P0 源直接使用 P1/P2

### 多语言规则
1. 如果 search_profile.query_languages 包含多语言，每层搜索使用全部指定语言
2. 中文源 + 英文源的结果独立提取后合并
3. 跨语言结果冲突时，以源语言的结果为准

### 来源可信度评级
- **高可信度**：同行评审学术论文、官方机构报告、权威百科全书
- **中可信度**：专家博客/文章、高质量媒体深度报道、知名科普平台
- **低可信度**：社交媒体、自媒体、论坛帖子（仅作为补充参考，需标注）
