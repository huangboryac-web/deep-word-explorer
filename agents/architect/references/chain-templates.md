# 学习链模板 (Chain Templates)

本文档定义六阶学习链中每一阶的内容骨架、必须包含的元素、可选元素和最低质量要求。

---

## 第一阶 · 原初印象（Hook）

### 阶段目标
让读者在 30 秒内建立对概念的基本认知，激发继续阅读的兴趣。

### 必须包含
1. **一句话定义**（50 字以内）：最精炼、最准确的定义
2. **生动类比**：来自日常生活的类比，让抽象概念具象化
3. **为什么你应该关心**：这个概念和你的生活/世界的联系（体现相关性）

### 可选包含
- 词源解析（如果有有趣的词源故事）
- 一个令人惊讶的事实（打破刻板印象）

### 内容骨架
```
┌────────────────────────────────────────────┐
│ ▎定义：{一句话定义}                         │
│                                              │
│ ▎类比：就像{类比描述}                       │
│                                              │
│ ▎为什么重要：{2-3句说明其重要性/相关性}      │
│                                              │
│ ▎初步印象：{让读者建立第一印象的额外视角}     │
└────────────────────────────────────────────┘
```

### 字数指导
- 最少：500 字
- 推荐：600-800 字

### 写作基调
**轻量、引人入胜**。不深入，不学术，像一个有趣的朋友在解释一个概念。

### 反面示例（禁止）
- ❌ "XX 是一个复杂的概念，本文将从多个角度……"（机械开场）
- ❌ 直接跳入历史或细节（渐进披露违规）
- ❌ 过于学术化或晦涩（与阶段目标不符）

---

## 第二阶 · 时空坐标（Context）

### 阶段目标
让读者理解这个概念「从哪来」「在何时何地产生」「由谁创造/发现」。

### 必须包含
1. **起源故事**：这个概念是怎么产生的（200-500 字）
2. **完整时间线**：从起源到现在的关键节点（5-20 个，渲染为时间线可视化）
3. **关键人物介绍**：3-8 个核心人物的生平和贡献
4. **地理/文化坐标**：这个概念在哪个文化/地域背景下产生

### 可选包含
- 前因：什么历史条件催生了这个概念
- 后果：这个概念产生后改变了什么
- 一组时代对比（当时 vs 现在的不同理解）

### 内容骨架
```
┌────────────────────────────────────────────┐
│ ▎起源：{起源故事}                           │
│                                              │
│ ▎时间线可视化：                              │
│   {date} → {event} → {significance}          │
│   {date} → {event} → {significance}          │
│   ...                                        │
│                                              │
│ ▎关键人物：                                  │
│   {name}：{role}。{contribution}              │
│   ...                                        │
│                                              │
│ ▎坐标：位于{geographic_scope}，{era}时代     │
└────────────────────────────────────────────┘
```

### 字数指导
- 最少：2,000 字
- 推荐：2,500-3,500 字

### 写作基调
**叙事性、有故事感**。像一个历史纪录片旁白。

---

## 第三阶 · 核心要素拆解（Anatomy）

### 阶段目标
将概念拆解为 3-6 个核心维度，每个维度深入解释。

### 必须包含
1. **3-6 个核心维度**，每个维度必须有：
   - 维度名称（一句话）
   - 「是什么」：该维度的定义和解释（200-500 字）
   - 「为什么重要」：该维度在整体中的关键作用（100-200 字）
   - 「一个例子」：具象化的案例（100-200 字）
2. **维度间逻辑关系**：各维度如何共同构成整体（200-300 字）

### 可选包含
- 维度对比表（如果维度间有清晰的对比关系）
- 视觉化：「核心要素卡片」（HTML 网格布局）

### 如何选择维度
从以下角度筛选 3-6 个最重要的维度：
- **结构维度**：概念由哪些部分组成
- **功能维度**：概念有什么作用/功能
- **类型维度**：概念有哪些类型/分支
- **过程维度**：概念涉及的步骤/阶段
- **关系维度**：概念涉及的关键关系/互动

### 维度命名规则
- 用精炼的名词短语（3-8 字）
- 避免学术行话（如果必须用专业术语，紧跟一句话解释）
- 维度名之间风格一致（如都用人性化的比喻，或都用准确的技术术语）

### 字数指导
- 最少：3,500 字
- 推荐：4,000-5,000 字

### 写作基调
**结构化、清晰**。像一个老师在拆解知识点，层层递进。

---

## 第四阶 · 深层机制（Mechanism）

### 阶段目标
解释「为什么是这样」——揭示底层逻辑、运作原理和因果链条。

### 必须包含
1. **因果链条**：从原因到结果的完整推理（3-7 步）
2. **底层逻辑**：为什么这个机制这样运作而不是那样（300-500 字）
3. **反事实分析**：如果不存在这个机制/概念，会发生什么（100-200 字）

### 可选包含
- 数学/形式化描述（仅当有明确的数学模型且适合展示时）
- 对比其他可能的机制（为什么不是 B 而是 A）
- 流程图/因果图可视化

### 因果链条构建规则
```
步骤 1: {初始条件/触发因素}
  ↓
步骤 2: {中间机制 1}
  ↓
步骤 3: {中间机制 2}
  ↓
步骤 N: {最终结果/表现}
```

每一步需要说明：
- **发生了什么**（what）
- **为什么发生**（why）——这是机制的核心
- **如果跳过这步**（counterfactual）

### 字数指导
- 最少：2,500 字
- 推荐：3,000-4,000 字

### 写作基调
**逻辑严密、层层推进**。像一个侦探在揭示案件背后的真相。

### 特别注意
- 这是全文最考验写作功力的部分
- 必须在解释深度和可读性之间找到平衡
- 如果概念的机制确实复杂：多用拆分和类比，不用简化到失真

---

## 第五阶 · 关联网络（Ecosystem）

### 阶段目标
将概念置于更大的知识网络中，展示它与其他概念的关系，帮助读者建立系统性理解。

### 必须包含
1. **前置概念清单**：理解这个概念需要先知道什么（3-5 个，每个附带一句话解释）
2. **平行概念对比**：与相似/可对比概念的横向比较（2-4 对）
3. **下游概念**：由这个概念引出或依赖这个概念的概念（3-5 个）
4. **知识图谱可视化**：SVG 内嵌的概念关系图
5. **推荐阅读路径**：如果想深入了解更多，下一步应该看什么（3-6 步）

### 可选包含
- 「你还需要知道的 N 个概念」清单（快速扩展阅读）
- 知识体系树状图

### 概念对比规范
```
{概念 A} vs {概念 B}
├─ 相同点：……
├─ 不同点 1：……
├─ 不同点 2：……
└─ 一句话总结：用 A 的场景 vs 用 B 的场景
```

### 字数指导
- 最少：2,000 字
- 推荐：2,500-3,500 字

### 写作基调
**全景视角、纵横交错**。像一个知识体系的管理员在绘制地图。

---

## 第六阶 · 批判视角（Critique）

### 阶段目标
跳出「学习模式」，切换到「批判模式」——展示这个概念的局限、争议和未解问题。

### 必须包含
1. **至少 2 个批判观点**：来自不同立场的质疑（每个 150-300 字）
2. **至少 2 个局限性**：这个概念在什么条件下不适用或被误解
3. **至少 2 个开放问题**：目前还没有答案的重要问题
4. **未来展望**：这个概念的可能发展方向（3-5 条）

### 可选包含
- 正反论点对照表
- 「如果你不同意……」的思考引导
- 其他学派/文化的替代性理解

### 批判观点结构
```
观点：{来自哪个学派/立场}
├─ 核心论证：……
├─ 证据支撑：……（标注来源）
├─ 对该批判的回应（如存在）：……
└─ 你的判断：这个批判的合理性和局限性
```

### 字数指导
- 最少：2,000 字
- 推荐：2,500-3,500 字

### 写作基调
**客观、平衡、启发思考**。不是来推翻前面五阶的内容，而是展示知识的边界和活力。

---

## 全局约束

### 六阶字数底线
| 阶 | 最少字数 |
|----|---------|
| 一 | 500 |
| 二 | 2,000 |
| 三 | 3,500 |
| 四 | 2,500 |
| 五 | 2,000 |
| 六 | 2,000 |
| **合计** | **≥ 12,500** |

### 每阶通用质量标准
- 至少引用 1-2 个来源（标注 ref_id）
- content_outline 的每个要点必须能在正文中找到对应段落
- 不引入后续阶才定义的概念（渐进披露）
