# 示例：新泽西（New Jersey）

本目录是 `deep-word-explorer` 的一次真实产出样例，直接用浏览器打开 [`index.html`](./index.html) 即可阅读。

## 元信息

| 项 | 值 |
|----|----|
| 解析词 | 新泽西（美国新泽西州） |
| 本体类型 | 地理实体 · 入门 · 共识 · 缓慢演变 |
| 深度 | `exhaustive`（穷尽式，全六阶 + 全五层搜索） |
| 主题 | 🌿 森林墨（Forest Ink） |
| 字数 | 9,089 个汉字（正文可见文本）；含标点、字母与数字约 12,124 字符 |
| 引用 | 正文 31 处 `[N]` 上标 + 20 条三级参考文献 |
| 体积 | 约 62 KB 单文件 HTML |

## 如何复现

把下面任意一条发给 Agent：

```text
用 deep-word-explorer 解析「新泽西」，主题用森林墨，深度 exhaustive。
```

```text
帮我深度解析一下「新泽西」，深度 exhaustive，主题森林墨。
```

## 说明

- 该样例用于演示「由浅入深 + 完整引用 + 单文件可读」的产出形态，不代表新泽西相关事实的最终权威版本。
- 交互组件：阅读进度条、目录侧栏、学习链指示器、术语 tooltip、引用弹层、暗色模式切换、PDF 导出（浏览器「打印 → 另存为 PDF」）。
- 如需更新内容，重新运行流水线即可生成新的 `index.html`。
